# HSE Metaverse Mods / CodeCraft

Инструментарий создания локаций HSE Metaverse: граф логики на Unity Entities, компоненты механики, версионируемый сериализатор, гибридный UI и экспорт локаций.

## Установка

Используйте отдельный проект Unity **6000.3.18f1**, Universal Render Pipeline. Установите Git и добавьте его в PATH.

В Package Manager выберите **Install package from git URL**:

```text
https://github.com/BurgProject/HSEVirtualSpaceMods.git
```

Либо добавьте запись в существующий объект dependencies файла Packages/manifest.json (не заменяйте весь манифест):

```json
"com.hseverse.mods": "https://github.com/BurgProject/HSEVirtualSpaceMods.git"
```

Для опубликованных проектов закрепляйте конкретный commit hash через `#<commit>` или существующий release tag. Значение version в package.json само по себе не фиксирует Git-ревизию. Тег `v1.0.0` можно использовать только после его публикации владельцем репозитория.

Latios и NodeGraphProcessor уже входят в SDK. Не устанавливайте вторые копии этих библиотек.

## Первый запуск

Дождитесь установки зависимостей и завершения компиляции. В SDK есть автоматический мастер настройки; повторный запуск доступен через **HSEverse/Setup**. Он добавляет scripting defines, импортирует CodeCraftModes.unitypackage и настраивает проект. Используйте новый проект: мастер изменяет настройки проекта. При запросе перезапуска редактора выполните его.

Откройте `Assets/Scenes/Main/ContentScene.unity`, затем подсцену `ContSub`. Создавайте логику в CodeCraft. Для сборки локации используйте ScriptableObject `PackageExporter`: задайте Build Path и выберите платформу. Экспорт локации и публикация SDK являются разными операциями.

Пользователям SDK не нужны исходники Roslyn-генератора и JSON-история типов. Сериализатор поставляется в `Scripts/Serialization/Generated`. Не добавляйте `HSE_WIRE_CODEGEN` в проект локации.

## Совместимость

Версия SDK, версии wire-компонентов и формат пакета локации различаются. Не сбрасывайте историю и TypeId опубликованных компонентов. Перед обновлением SDK сохраните проект и проверьте экспорт на соответствующей версии приложения метаверса.

Встроенные зависимости сохраняют собственные лицензии. Публичность репозитория сама по себе не предоставляет лицензию на код HSE; условия распространения собственного кода должен определить правообладатель.

## Подготовка репозитория SDK

Используйте **Export SDK** в редакторе Unity, затем вручную перенесите файлы пакета с заменой в папку репозитория, сохраняя `.git`. Обычное копирование с заменой не удаляет устаревшие файлы: удалённые из SDK файлы нужно убрать и из экспортной копии. Если менялись сериализуемые типы, предварительно обновите SDK Serializer штатным инструментом проекта.

Перед публичным выпуском обязательны проверка импорта в чистый Unity-проект, проверка лицензий вложенных библиотек и создание неизменяемой версии/tag. Эти проверки не заменяются копированием файлов.
